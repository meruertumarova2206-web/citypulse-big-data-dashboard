# CityPulse — открытые данные о качестве воздуха

Адаптивная панель загружает актуальную модельную оценку качества воздуха через открытый Open-Meteo Air Quality API. Можно выбрать Алматы, Астану или Шымкент, посмотреть AQI и концентрации частиц/диоксида азота, исследовать почасовой ряд и скачать значения в CSV.

**Открыть опубликованный сайт:** <https://meruertumarova2206-web.github.io/citypulse-big-data-dashboard/>

> Значения приходят из глобальной модели CAMS и являются расчётной оценкой для ячейки сетки около 45 км. Это не прямые показания городской станции; локальные условия могут отличаться. Доступность API и точность прогноза не гарантируются поставщиком.

## Возможности

- Текущие модельные значения для трёх городов Казахстана.
- Переключение графика между US AQI, PM₂.₅ и PM₁₀ и выбор периода 6, 12 или 24 часа.
- Таблица почасовых значений и экспорт временного ряда в CSV.
- Обновление по кнопке, обработка недоступности API и кэширование ответа на 15 минут.
- Светлая/тёмная темы, мобильная навигация, семантическая разметка и состояния для скринридера.
- Атрибуция CAMS и Open-Meteo на странице.

Это учебный прототип визуализации временных рядов, а не промышленная Big Data-платформа: он загружает небольшой набор данных напрямую из API и не хранит многолетнюю историю.

## Источник данных и лицензия API

- [Open-Meteo Air Quality API](https://open-meteo.com/en/docs/air-quality-api) — текущие оценки и почасовые поля.
- [CAMS Global Atmospheric Composition Forecast](https://atmosphere.copernicus.eu/) — модельный источник, который покрывает выбранные города.
- Данные Open-Meteo предоставляются по [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); на сайте размещена требуемая атрибуция CAMS и Open-Meteo.
- Бесплатный API Open-Meteo разрешён для некоммерческого использования. Для коммерческого проекта нужно оформить подходящий доступ у поставщика.

## Локальный запуск

Инструкция ниже нужна, если вы хотите запустить копию сайта на своём компьютере. В этом случае `localhost` — адрес только этого компьютера; для просмотра опубликованной версии используйте ссылку выше. Нужны Python 3 и подключение к интернету для запроса открытого API. Установка зависимостей не требуется.

```bash
python3 -m http.server 8000
```

Откройте <http://localhost:8000>.
