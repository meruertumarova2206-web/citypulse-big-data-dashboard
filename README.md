# CityPulse — аналитика городских данных

Адаптивная демонстрационная панель о том, как анализ больших данных помогает понимать городскую мобильность. Интерфейс показывает объёмы потока, состояние источников, качество данных и пример обнаружения аномалий.

**Открыть опубликованный сайт:** <https://meruertumarova2206-web.github.io/citypulse-big-data-dashboard/>

> Все числа и наборы данных в проекте синтетические. Панель не подключена к городским датчикам и внешним API.

## Возможности

- Главная панель с KPI, трендом потока событий и состоянием источников данных.
- Переключение периода графика: 7, 30 или 90 дней.
- Переключение метрики: объём потока или число обнаруженных аномалий.
- Поиск наборов данных и фильтр по региону.
- Экспорт отфильтрованного каталога в CSV.
- Светлая и тёмная темы, мобильная навигация, адаптация для небольших экранов.
- Русский интерфейс, семантическая HTML-разметка и состояния для скринридера.

## Локальный запуск

Инструкция ниже нужна, если вы хотите запустить копию сайта на своём компьютере. В этом случае `localhost` — адрес только этого компьютера; для просмотра опубликованной версии используйте ссылку выше. Нужен Python 3 или любой простой локальный HTTP-сервер. Установка зависимостей не требуется.

```bash
python3 -m http.server 8000
```

Откройте <http://localhost:8000>.
